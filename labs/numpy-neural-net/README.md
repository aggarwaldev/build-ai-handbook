# A neural network from scratch

Forward pass, backpropagation, mini-batches and a gradient check, in NumPy only.
The walkthrough is in `project-neural-net.html` (chapter 15).

From the repository root:

    pip install -r labs/numpy-neural-net/requirements.txt
    python labs/numpy-neural-net/train.py --gradcheck
    python labs/numpy-neural-net/train.py --plot
